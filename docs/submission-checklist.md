1. Record requirements and acceptance criteria.
2. Define the selected product, architecture, and domain model.
3. Implement and test application logic and persistence.
4. Implement complete user workflows and responsive interface.
5. Validate reliability, accessibility, and production build.
6. Complete deployment, evaluator documentation, demo, and submission evidence.

Each milestone should produce its own honest commit; never fabricate dates or backfill a misleading history.
